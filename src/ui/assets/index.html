Cài đặt

  • Tìm tên tab Ctrl + /
  • Chuyển tiếp tab (Cycle) Ctrl + Tab
  • Chuyển lùi tab Ctrl + Shift + Tab
  • Tạo tab mới Ctrl + N
  • Tạo ô việc cần làm []
  • Cú pháp hẹn giờ @15:30 15/11 hoặc @mai 09:00
  • Xem ảnh phóng to Double-click ảnh
